tpscraper authorization

For your own account and authorized local use only. When your paired process requests renewal, Chrome will request a fresh token from TakeProfit and deliver it only to that process on your computer. Pair once per installed extension. Reuse the saved pairing; a new code is needed only if you reset it or change browser profiles. Keep Chrome signed in. If updating, reload this extension and disable old duplicate copies. Disable renewal here to remove the pairing; an already issued token may remain valid until expiration.
